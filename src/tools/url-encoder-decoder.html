What is URL encoding?

URLs can only contain a limited set of characters. Spaces, accented letters, emoji and symbols like &, ? and # must be percent-encoded: each byte becomes % followed by two hex digits. For example, a space becomes %20 and é becomes %C3%A9.

URL breakdown

When the input is a full URL, the tool splits it into protocol, host, path, query parameters and fragment, with every parameter decoded. That makes long tracking links, redirect URLs and API requests easy to read and debug.

Frequently asked questions

Why does my decoded URL still contain %25?

%25 is an encoded percent sign, which means the text was encoded twice. Click Decode again to decode the second layer.

When should I treat + as a space?

HTML forms encode spaces as + in query strings (application/x-www-form-urlencoded). Tick the option when decoding form submissions or search URLs like ?q=hello+world.

Is my data sent anywhere?

No. Encoding and decoding happen in your browser.
