How to split a PDF

  1. Choose the PDF you want to split.
  2. Type the pages you need, for example 1-3, 5, 8-10. Leave it empty to use every page.
  3. Pick an output:
    • One PDF extracts the selected pages into a single new file.
    • Separate PDF for each range creates one file per range: 1-3, 5 and 8-10 become three files.
    • Separate PDF for every page splits the selected pages into single-page files.
  4. Click Split PDF and your files download automatically.

Frequently asked questions

How do I delete pages from a PDF?

Enter only the pages you want to keep. For example, to remove page 4 from a 10-page PDF, enter 1-3, 5-10 and choose "One PDF".

Can I reorder pages?

Yes. Pages are output in the order you type them, so 3, 1, 2 puts page 3 first.

My browser only downloaded one file. Why?

Some browsers ask permission before downloading several files from one page. Look for a prompt in the address bar and choose "Allow".

Are my files uploaded?

No. Splitting happens entirely in your browser, so confidential documents never leave your device.
