How to compare two texts

  1. Paste the original text on the left and the changed version on the right.
  2. Click Compare.
  3. Removed lines are shown in red and added lines in green. The exact words that changed within a line are highlighted more strongly.

What can I compare?

  • Document revisions: see what an editor or co-author changed in an essay, contract or article.
  • Code: compare two versions of a config file, script or SQL query.
  • Lists and data: find which rows were added or removed between two exports.
  • Plagiarism checks: quickly spot copied passages between two texts.

Options

  • Ignore case treats "Hello" and "hello" as identical.
  • Ignore whitespace ignores differences in spaces and indentation, which is useful for code and copy-pasted text.
  • Show only changes hides long unchanged sections and keeps 3 lines of context around each change.

Frequently asked questions

Is my text sent to a server?

No. The comparison runs in your browser, so confidential documents and code stay private.

How does the comparison work?

It uses the Myers diff algorithm, the same approach used by Git, to find the smallest set of line insertions and deletions. Then it compares changed lines word by word.

How large can the texts be?

Thousands of lines compare instantly. Very large inputs with many differences may take a few seconds.
